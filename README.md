# Personal Blog – Underreacted

## Project Description

Underreacted is a simple personal blog built using React. It demonstrates component-based development and the use of props to pass data between components.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Project Components

### App.jsx
The main component that brings all the blog components together.

### Header.jsx
Displays the blog name.

### About.jsx
Displays the blog logo and blog description.

### ArticleList.jsx
Uses the map() method to display a list of blog articles.

### Article.jsx
Displays an individual article's title, publication date and preview.

## Component Relationships

- App connects to Header, About and ArticleList.
- ArticleList connects to Article.
- App passes blog information and posts to its child components through props.

## How to Run the Project

1. Clone the repository:

   
   git clone YOUR_GITHUB_REPOSITORY_URL
   

2. Navigate into the project directory:

  
   cd react-components-props-vite-lab
   

3. Install dependencies:

   
   npm install
   

4. Start the development server:

   
   npm run dev
   

5. Open the local URL displayed in your terminal:

   `http://localhost:5173/`
